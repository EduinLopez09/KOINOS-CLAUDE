# KOINOS · Somos Jóvenes LDA
1. Supabase → SQL Editor: pega y ejecuta `supabase.sql`.
2. Authentication → Add user (marca *Auto Confirm User*) por cada líder/maestro; luego corre el `insert` comentado al inicio del SQL.
3. `cp .env.example .env` y completa URL y anon key (Project Settings → API).
4. `npm install && npm run dev`
